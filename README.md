# Information Retrieval Projekt – MAS Data Science

Dieses Projekt wurde im Rahmen des MAS Data Science erstellt und behandelt grundlegende Konzepte des Information Retrieval.

Der Fokus liegt auf der Analyse und Verarbeitung von Textdaten sowie der Anwendung von Methoden zur Suche, Strukturierung und Interpretation von Informationen.

---

## 📚 Projektübersicht

Das Repository enthält mehrere Jupyter Notebooks, welche verschiedene Aspekte des Information Retrieval demonstrieren:

* **1_FOMC_statements.ipynb**
  Analyse von FOMC-Statements (Federal Reserve) zur Untersuchung von Textinhalten und sprachlichen Mustern

* **2_Zigzag.ipynb**
  Implementierung bzw. Demonstration eines Algorithmus (z. B. Zigzag Join) im Kontext von Information Retrieval

* **IR_data.xlsx**
  Datengrundlage für Analysen und Experimente

---

## 🎯 Ziel des Projekts

Ziel ist es, zentrale Konzepte des Information Retrieval praktisch anzuwenden, insbesondere:

* Verarbeitung und Analyse von Textdaten
* Verständnis von Such- und Matching-Algorithmen
* Anwendung einfacher Ranking- oder Filtermechanismen
* Exploration von Mustern in Dokumenten

---

## ⚙️ Voraussetzungen

Für die Ausführung werden folgende Tools benötigt:

* Python 3.9 oder neuer
* Jupyter Notebook oder JupyterLab

Typische verwendete Libraries:

* pandas
* numpy
* matplotlib
* scikit-learn (optional)
* nltk oder spaCy (für Textverarbeitung)

## 🚀 Installation

Repository klonen:

```bash
git clone https://github.com/niciamcompi/<repo-name>.git
cd <repo-name>
```

Virtuelle Umgebung erstellen (empfohlen):

```bash
python -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows
```

Abhängigkeiten installieren:

```bash
pip install -r requirements.txt
```
